Non-obvious constraints discovered during grounding, worth keeping in mind across stages:

- `dd` does not honor `json` tags. The report DTOs therefore need a `dd:",+omitempty"` flag wherever a JSON `omitempty` must also apply on disk (`reason`); nil pointers are already omitted by dd on unbind, which is what carries the historical-nil-coverage distinction through status/result files.

- `ToolAnnotations.ReadOnlyHint` is a plain bool in this SDK version while `DestructiveHint` is `*bool`; the explicit `destructiveHint: false` in discovery needs a non-nil pointer.
- New git fixture tests should pass `-c commit.gpgsign=false` per the work order's host note, even though existing fixtures currently pass without it here.
